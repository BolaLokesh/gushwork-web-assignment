# Gushwork Web Developer Assignment

## Overview
Responsive web page implementing Figma design specifications with interactive features.

## Live Preview
Open `index.html` in any modern browser.

## Features Implemented
- ✅ **Sticky Header** - Appears when scrolling beyond first fold, hides on scroll up
- ✅ **Image Carousel** - Smooth horizontal scroll with next/prev navigation
- ✅ **Zoom-on-Hover** - Images scale smoothly when hovering
- ✅ **Responsive Design** - Works on desktop, tablet, and mobile devices
- ✅ **Pixel-perfect** - Matches Figma specifications

## Tech Stack
- HTML5 (Semantic elements)
- CSS3 (Flexbox, Grid, animations, responsive design)
- Vanilla JavaScript (No frameworks/libraries)
